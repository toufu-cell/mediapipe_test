Progress 1 / Capture System

PC を司令塔にして、動画と手首 IMU を同じ session にした

iPhone は映像、Apple Watch は手首の動きを担当し、session ID で後処理時に紐づける。

実装済みiOS / watchOS
PC

Capture Session

Start / Stop command を作り、iPhone TCP :8765 へ送る。session ID、予定開始時刻、同期 gesture を固定する。

command: start / stop JSON
iOS

iPhone Recorder

front camera で調理動画を記録し、録画後に Photos に保存する。Watch へ同じ command を relay する。

output: <sessionId>.mov
W

Apple Watch IMU

CoreMotion の userAcceleration と rotationRate を記録し、CSV を iPhone へ転送する。

output: accel / gyro / norm CSV
低負担に「同じ調理行動」を映像と手首センサで記録する土台 02 / 06

Progress 2 / Synchronization

3回振り gesture で Pose と IMU の時刻を合わせる

動画側の手首速度と Watch 側の gyro_norm のピークを対応させ、残った offset を推定する。

実装済みsync_session.py

Video signal: wrist speed

Watch signal: gyro_norm

offset_ms を推定 3つのピーク間隔と offset のばらつきから、安定した対応だけを採用する。
synced_pose_imu.csv を出力 Pose timestamp に最も近い IMU サンプルを結合し、分類入力へつなげる。
sync_diagnostic.png を生成 同期が合っているかを目視確認できる補助図として残す。
このスライドには実データの diagnostic plot を差し替え画像として載せると説得力が上がる 03 / 06
